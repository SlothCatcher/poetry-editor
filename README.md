# Строка — редактор стихов

Веб-приложение на React, React-Bootstrap и Vite. Деление русских слов на слоги — библиотека `syllables-ru`.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, напечатанный Vite. Для сборки: `npm run build`.

## Возможности

- Создание, редактирование и удаление стихотворений; экспорт текущего стихотворения в TXT.
- Текстовый режим: число русских гласных (слогов) справа от каждой строки. Длинные строки не переносятся, их можно прокручивать по горизонтали.
- Ручная постановка ударения: установите курсор сразу после русской гласной и нажмите **Ctrl + Enter** или кнопку «Ударение». Повторное нажатие снимает метку. Ударение хранится как стандартный комбинируемый символ U+0301 и включается в TXT.
- Режим сетки: по клетке на слог; ударные клетки подсвечены. Это представление для просмотра; редактирование — в текстовом режиме.

Разбиение на слоги ориентировано на русский язык и носит автоматический, приблизительный характер. Ударения автоматически не определяются, рифмы и метр не анализируются. Знаки препинания и пробелы присоединяются к соседней клетке; строки без гласных показаны как текст без клеток.

Данные хранятся в localStorage браузера на текущем устройстве и не синхронизируются. При очистке данных браузера они могут исчезнуть — скачивайте важные тексты.
