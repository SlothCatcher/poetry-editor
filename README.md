# Строка — редактор стихов

Простой сайт для написания и редактирования стихотворений.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Возможности

- Несколько стихотворений: создание, редактирование и удаление.
- Автоматическое сохранение в localStorage браузера на текущем устройстве.
- Подсчёт слов и строк, скачивание текущего стихотворения в TXT.
- Адаптация для мобильных экранов.

Данные не синхронизируются между устройствами и могут исчезнуть при очистке данных браузера. Скачивайте важные тексты. Шрифты загружаются из Google Fonts; при отсутствии сети используются системные шрифты.
